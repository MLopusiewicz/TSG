\## Baking



Made window with basic setup Size and Offset to control baked volume and VoxelSize - to control resolution.

Output is saved in Texture3D (raw sdf data) and ScriptableObject holding texture reference and baked volume data.



Baking is based on SDFItem - monobehaviour added to scene objects. Mostly for easy, manual setup. Lacks rotation support.
