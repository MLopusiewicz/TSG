\## Baking



Made window with basic setup to control baked bounds and resolution.

Output is saved in Texture3D (raw distance data) and ScriptableObject holding texture reference and baked volume data.



Baking is based on SDFItem - MonoBehaviour added to scene objects. Mostly for easy, manual setup. Lacks rotation support in and nonuniform scaling in cylinder.
